# 0.3.2 公开验证与验收摘要

当前源码版本为 0.3.2。2026-10-11 发布前，在 macOS arm64、Python 3.14.6 上运行 `python3 -m unittest discover -s tests -p 'test_*.py' -q`，207 项全部通过。此前本地交付记录另验证了 Python 3.12.14 的 207 项测试；该历史记录保留在作者本地，不以它代替本次检查。Linux、Windows 和 Python 3.11 未验证，本版最低声明为 Python 3.12。

## 工程行为与修复

- 默认使用本地排序；只有显式 `--mode jev` 才调用外部评分。
- 搜索和解析共用安全捕获的源码快照，在评分前与返回前核验源文件指纹。
- 新的计划和读取工具校验路径、行范围与指纹，支持清单外补读和已读区间去重；目标代码不被导入或执行。
- 0.3.1 修复日志硬链接写入、指纹核验读取漏计、深层 JSON 导致已成功评分丢失的问题。
- 0.3.2 修复临时目录与可选 tokenizer 缓存落入目标仓库的边界；没有可用安全目录时拒绝或明确回退。
- 回归覆盖源码变化、符号链接替换、JSON 失败隔离、评分超时、临时目录边界和实验评分预算。

计量区分源码捕获与两次指纹核验的实际读取。成功命令的目标源码累计读取可达约 96 MiB；捕获预算为 32 MiB。整机 I/O、模型服务端 usage、实际 HTTP 请求数与账单未知。评估 v2 使用冻结的旧 0.3.0 实现，其旧计量限制不改称当前版本效果。
